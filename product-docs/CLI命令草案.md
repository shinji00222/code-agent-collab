# CLI命令草案

## 目标

第一版先做命令行工具，不做复杂界面。命令行工具负责创建任务、整理上下文包、保存任务日志和生成候选复利记录。

## 命令名称

暂定命令名：

```powershell
agent-workbench
```

后续如果需要中文名，可以只作为界面展示名，命令本身保持英文，方便在 PowerShell、GitHub Actions 和脚本中使用。

## 第一版命令

### 初始化项目配置

```powershell
agent-workbench init
```

作用：

- 检查当前目录是否是 Git 仓库；
- 创建本项目需要的目录；
- 生成本地配置文件；
- 不写入主知识库。

### 创建任务上下文包

```powershell
agent-workbench start "任务目标"
```

作用：

- 接收用户任务目标；
- 读取项目文档；
- 读取 dev-vault；
- 按用户指定范围只读读取主知识库；
- 生成任务上下文包；
- 写入 `logs`。

### 生成候选复利记录

```powershell
agent-workbench reflect --task <任务ID>
```

作用：

- 读取任务日志；
- 总结可复用经验；
- 生成候选复利记录；
- 写入 `dev-vault/pending`；
- 不直接写入主知识库。

### 查看候选记录

```powershell
agent-workbench pending
```

作用：

- 列出 `dev-vault/pending` 中等待确认的候选复利记录；
- 显示来源任务、验证状态和建议写入位置。

## 第一版不做的命令

- 不做自动同步主知识库命令；
- 不做删除主知识库内容命令；
- 不做部署命令；
- 不做账号和云端协作命令。

## 命令设计原则

- 默认只读主知识库；
- 所有自动写入先进入 dev-vault；
- 需要破坏性操作时停止并提示用户；
- 每个任务都留下可审计日志；
- 命令输出尽量短，详细内容写入文件。
