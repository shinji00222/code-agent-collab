# MVP范围



## MVP目标



第一版只跑通一个最小闭环：



用户输入一个任务，系统读取相关知识库内容，生成任务上下文包，辅助 AI 完成任务，最后生成候选复利记录。



## 第一版要做



- 读取项目测试知识库 dev-vault。

- 只读读取主知识库中的指定文件或目录。

- 根据任务关键词找出相关笔记。

- 生成任务上下文包。

- 记录任务过程日志。

- 生成候选复利记录。

- 候选记录写入 dev-vault/pending。

- 用户确认后，才允许同步到主知识库。



## 第一版不做



- 不做账号系统。

- 不做云同步。

- 不做多人权限。

- 不做复杂前端界面。

- 不自动修改主知识库。

- 不直接接管所有 AI 工具。

- 不做插件市场。

- 不做商业化功能。



## 成功标准



第一版完成后，应该能做到：



- 输入一个任务目标；

- 自动找到相关知识库内容；

- 输出一个清晰的上下文包；

- 任务结束后生成一条候选复利记录；

- 候选记录保存到 dev-vault/pending；

- Git 能记录每次知识库规则和项目文档变化。
