# 任务上下文包格式

## 目标

任务上下文包用于把一个任务需要的背景、限制、证据和完成标准整理成统一格式，交给 AI Agent 使用，减少重复解释和上下文遗漏。

## 基本信息

- 任务标题：
- 用户原始请求：
- 当前项目路径：
- 当前 Git 分支：
- 当前 Git 状态：
- 任务开始时间：
- 任务完成标准：

## 知识库范围

- 知识检索来源：
- 知识写入目标：
- dev-vault 可读写范围：
- 本次禁止读取的范围：
- 本次禁止写入的范围：

## 上下文选择记录

- [task] 用户原始请求：
- [repo] Git 分支与状态：
- [project-doc] product-docs/<文档名>：
- [code] src/<代码文件> 或 tests/<测试文件>：

## Token 预算估算

- 已选上下文约：
- 项目文档选择上限：
- 代码文件选择上限：
- 说明：

## 相关资料

- 相关项目文档：

- 相关历史踩坑：
- 相关代码文件（路径、选择理由、粗略 token）：

## 代码文件摘录

每个入选代码文件写一个小节，保留短摘录即可，不复制全仓库：

````text

```python
<代码摘录>
```
````
